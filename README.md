# Tiger Detailing Booking Platform

A full-stack car detailing booking platform built for Tiger Detailing Auto Services.

The application allows customers to view detailing services, book appointments, manage existing bookings, and interact with a responsive web interface.

## Features

- Responsive React frontend
- Online appointment booking
- View existing bookings
- Edit appointment service, date, and time
- Cancel bookings
- MySQL database integration
- REST API built with Node.js and Express
- Form validation
- Prevents users from selecting past booking dates
- Responsive layout for desktop and mobile devices
